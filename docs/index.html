Guiding Principles

Built for developers who want their machine back.

AstraIDE strips away background telemetry, indexing stalls, and multi-gigabyte memory footprints.

Lightweight

Native Rust core with a minimal desktop shell. Keeps CPU and RAM available for your compiler and Gradle builds.

Physical-device first

Connect your Android phone over USB or Wi-Fi and deploy directly without spinning up resource-intensive emulators.

Offline by design

Edit, build, debug and deploy locally without cloud services, account logins, or background tracking.

Focused

Only the tools needed for Android development stay in your workspace, keeping the entire interface fast and predictable.

Capabilities

Everything essential for Android engineering.

Designed to orchestrate the official Android platform toolchain through a high-performance desktop interface.

Code Editor

Fast CodeMirror 6 editor with support for Kotlin, Java, XML, Gradle, JSON and Markdown editing with instantaneous tab switching.

Device Manager

Detect USB and Wi-Fi Android devices, view device hardware information, battery status, and deploy APKs directly.

Live Logcat

High-throughput Logcat viewer with filtering by log level, PID, package identifier, and real-time text matching.

Gradle Builds

Run real Gradle wrapper commands (assembleDebug, installDebug, clean) and stream structured build output in real time.

APK Analyzer

Inspect APK structure, DEX classes, ABI native architectures, asset payloads, and AndroidManifest metadata.

Environment Diagnostics

Automatically verify JDK paths, Android SDK platform tools, ADB server daemon, Git binary, and connected devices.

Storage Analyzer

Inspect Android SDK platforms, Gradle caches, emulator system images, and project build artifact storage usage.

Integrated Terminal

Embedded PowerShell and Command Prompt initialized directly inside the active Android project root directory.

Git Integration

View staged and unstaged file changes, branch topology, commit diffs, and perform repository commits without leaving AstraIDE.

System Architecture

Clean process separation and native orchestration.

How AstraIDE bridges web technologies, the Rust systems layer, and the Android SDK.

Android SDK Toolchain & Physical Android Device Target device execution via adb over USB or TCP/IP

Native Subprocess Model

AstraIDE executes official SDK binaries directly via structured process arguments. It avoids in-process JVM embedding, ensuring crashes or memory spikes in builds never affect the IDE.

Asynchronous Event Stream

Logcat lines, build milestones, and ADB device state changes are piped from background Rust threads straight to the user interface via lightweight Tauri events.

No Heavy Background Daemon

When AstraIDE closes, its background helpers cleanly terminate. No rogue background indexing processes stay resident on your Windows workstation.

Getting Started

Up and running in minutes.

No multi-step setup wizards or gigabytes of bundled dependencies.

01

Download AstraIDE

Download the prebuilt Windows standalone executable or installer directly from the GitHub releases page.

Download AstraIDE v0.1.0
02

Check your environment

Ensure your machine has the required development toolchain installed. AstraIDE verifies these paths automatically upon launch.

Windows 10/11 x64 • JDK 17 or 21 • Android SDK • Platform Tools • Build Tools
03

Connect your device

Enable USB Debugging on your Android handset in Developer Options, attach the USB cable, and authorize the computer prompt.

adb devices
04

Open a project

Select Open Project from the welcome dashboard and point to any existing Android Gradle repository (or generate a starter template).

05

Build and run

Select your target Android device in the top navigation bar and press F5. AstraIDE triggers the Gradle wrapper, installs the generated APK, and automatically opens live Logcat.

Prerequisites

System requirements.

AstraIDE coordinates the standard Android toolchain rather than replacing Android SDK or Gradle itself.

Requirement Specification / Details
Operating System Windows 10 / Windows 11 (64-bit)
Java Development Kit JDK 17 or JDK 21 (Temurin, OpenJDK, or Oracle)
Android SDK Required (configured via ANDROID_HOME or AstraIDE settings)
Platform Tools Required (contains adb.exe)
Build Tools Required (contains aapt2.exe, zipalign.exe)
Physical Device Recommended (USB or Wi-Fi with USB debugging enabled)
Emulator (AVD) Optional (supported when an Android Virtual Device is configured)

AstraIDE orchestrates the official Android toolchain rather than replacing Android SDK/Gradle itself.

Local First

Your project stays on your machine.

No accounts, no external cloud dependencies, and zero code upload telemetry.

Offline-first

AstraIDE is designed to operate locally. All parsing, file editing, and diagnostics run directly on your hardware without internet connectivity.

Zero telemetry

No cloud telemetry, tracking pixels, or source-code uploads. Your codebase and project structure are strictly confidential to your machine.

Local builds

Gradle builds execute on the user's machine through official local wrappers without intermediary remote build services.

Safe process execution

External tools such as Gradle, ADB and Git are executed using structured process arguments without raw arbitrary shell evaluation.
